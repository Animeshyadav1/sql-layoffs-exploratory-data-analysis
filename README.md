# 📊 SQL Layoffs Exploratory Data Analysis Project

## 📌 Project Overview
This project focuses on performing exploratory data analysis (EDA) on a real-world layoffs dataset using MySQL.

The analysis was performed after completing the data cleaning process to identify trends, patterns, and insights related to layoffs across companies, industries, countries, and years.

---

## 🛠️ Tool Used
- MySQL

---

## 🔍 Analysis Performed
- Analyzed total layoffs by company
- Identified industries with highest layoffs
- Analyzed layoffs by country
- Explored yearly layoff trends
- Examined company funding stages
- Calculated rolling monthly layoff totals
- Ranked companies by yearly layoffs using `DENSE_RANK()`
- Identified companies with 100% layoffs

---

## 📚 SQL Concepts Used

```sql
GROUP BY
ORDER BY
AGGREGATE FUNCTIONS
WINDOW FUNCTIONS
CTE
DENSE_RANK()

SUBSTRING()
```

## 📂 Project Workflow
1. Imported cleaned layoffs dataset

4. Performed industry-level analysis
5. Analyzed country-wise layoffs
6. Examined yearly layoffs trends
